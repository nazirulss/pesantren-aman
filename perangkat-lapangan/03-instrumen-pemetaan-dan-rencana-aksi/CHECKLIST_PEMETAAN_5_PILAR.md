### **LEMBAR EVALUASI INDIKATOR 5 PILAR**

Beri tanda cek (**✓**) pada kolom status:
* **[ 1 ] Belum Ada:** Belum menjadi kebiasaan atau belum memiliki aturan.

### **PILAR 1: PENGASUHAN YANG AMAN DAN BERMARTABAT**
*Fokus: Pola asuh mendidik, perlindungan martabat anak, dan disiplin tanpa kekerasan fisik/verbal.*

| No | Indikator Refleksi | 1 | 2 | 3 | Catatan Kondisi Lapangan & Praktik Baik |
|:---|:---|:---:|:---:|:---:|:---|
| 1.1 | Pesantren memiliki panduan sanksi edukatif tertulis (tanpa hukuman tamparan, pukulan fisik, atau sanksi yang mencederai kesehatan santri). | [ ] | [ ] | [ ] | |
| 1.2 | Pengurus keamanan kamar/asrama memahami larangan perpeloncoan, piket sewenang-wenang, dan senioritas berlebihan antar santri. | [ ] | [ ] | [ ] | |
| 1.3 | Terdapat jadwal pengawasan/ronda malam oleh ustadz/pengurus pembina di kompleks kamar santri. | [ ] | [ ] | [ ] | |
| 1.4 | Pembina kamar mengedepankan pendekatan keteladanan akhlak, muhasabah, dan dialog kasih sayang (*tarbiyah bi-rahmah*). | [ ] | [ ] | [ ] | |
| 1.5 | Santri baru mendapatkan bimbingan adaptasi yang ramah tanpa rasa takut pada masa awal masuk asrama. | [ ] | [ ] | [ ] | |

---

### **PILAR 2: KEPATUHAN HUKUM DAN LITERASI PERLINDUNGAN**
*Fokus: Pemahaman regulasi perlindungan anak, batasan hukum pidana, dan hak santri.*

| No | Indikator Refleksi | 1 | 2 | 3 | Catatan Kondisi Lapangan & Praktik Baik |
|:---|:---|:---:|:---:|:---:|:---|
| 2.1 | Pengasuh dan dewan asatidz pernah mendapatkan pengenalan literasi dasar terkait UU Perlindungan Anak & UU TPKS. | [ ] | [ ] | [ ] | |
| 2.2 | Dewan ustadz memahami batasan hukum dalam mendisiplinkan santri guna melindungi diri dari tuduhan tindak pidana (*self-protection*). | [ ] | [ ] | [ ] | |
| 2.3 | Pesantren memiliki kontak rujukan layanan hukum atau koordinasi dengan Satgas RMI NU / PPA Polres Demak. | [ ] | [ ] | [ ] | |
| 2.4 | Pesantren memiliki mekanisme perlindungan privasi santri (tidak mengekspos foto santri bermasalah ke medsos publik). | [ ] | [ ] | [ ] | |
| 2.5 | Informasi hak-hak santri untuk belajar secara aman disampaikan secara terbuka kepada santri dan wali santri. | [ ] | [ ] | [ ] | |

---

### **PILAR 3: TATA KELOLA DAN TANGGUNG JAWAB KELEMBAGAAN**
*Fokus: Kebijakan tertulis, pembagian peran, struktur kepengurusan, dan komunikasi wali santri.*

| No | Indikator Refleksi | 1 | 2 | 3 | Catatan Kondisi Lapangan & Praktik Baik |
|:---|:---|:---:|:---:|:---:|:---|
| 3.1 | Terdapat Buku Tata Tertib Pengasuhan Santri yang tertulis rapi dan dibagikan kepada wali santri saat pendaftaran. | [ ] | [ ] | [ ] | |
| 3.2 | Terdapat penunjukan resmi ustadz/ustadzah sebagai Penanggung Jawab Kesejahteraan / Perlindungan Santri. | [ ] | [ ] | [ ] | |
| 3.3 | Pesantren memiliki buku mutasi / catatan kejadian pelanggaran santri yang terdokumentasi secara rapi dan rahasia. | [ ] | [ ] | [ ] | |
| 3.4 | Pengurus asrama mendapatkan pembekalan tertulis sebelum menjalankan amanah kepengurusan harian. | [ ] | [ ] | [ ] | |
| 3.5 | Adanya saluran komunikasi berkala antara pengurus pondok dan wali santri terkait perkembangan santri. | [ ] | [ ] | [ ] | |

---

### **PILAR 4: SISTEM PERLINDUNGAN DAN PENGADUAN**
*Fokus: Ketersediaan kanal curhat aman, jaminan kerahasiaan, dan penanganan awal.*

| No | Indikator Refleksi | 1 | 2 | 3 | Catatan Kondisi Lapangan & Praktik Baik |
|:---|:---|:---:|:---:|:---:|:---|
| 4.1 | Tersedia kanal pengaduan/curhat santri yang aman (misal: kotak surat rahasia, ruang konseling ustadzah/ustadz). | [ ] | [ ] | [ ] | |
| 4.2 | Santri merasa yakin bahwa identitas pelapor dijamin kerahasiaannya dan dilindungi dari ancaman balas dendam kawan/senior. | [ ] | [ ] | [ ] | |
| 4.3 | Terdapat prosedur respons awal (SOP) ketika menerima laporan kekerasan: mengamankan korban, tidak menghakimi, dan melapor ke pengasuh. | [ ] | [ ] | [ ] | |
| 4.4 | Tersedia layanan pendampingan kesehatan dasar/pertolongan pertama (UKS/Poskestren) yang tanggap terhadap luka/sakit santri. | [ ] | [ ] | [ ] | |
| 4.5 | Pengurus tidak menyelesaikan kasus dugaan kekerasan berat secara sepihak yang merugikan pemulihan santri korban. | [ ] | [ ] | [ ] | |

---

### **PILAR 5: EVALUASI DAN PERBAIKAN BERKELANJUTAN**
*Fokus: Komitmen perbaikan berkala, tindak lanjut evaluasi, dan budaya belajar.*

| No | Indikator Refleksi | 1 | 2 | 3 | Catatan Kondisi Lapangan & Praktik Baik |
|:---|:---|:---:|:---:|:---:|:---|
| 5.1 | Pengasuh dan pengurus mengadakan rapat evaluasi pola pengasuhan santri secara berkala (minimal 1 bulan sekali). | [ ] | [ ] | [ ] | |
| 5.2 | Pesantren bersedia membuka diri terhadap pendampingan perbaikan sistem pengasuhan dari RMI NU Demak. | [ ] | [ ] | [ ] | |
| 5.3 | Pesantren merumuskan target perbaikan konkret dalam siklus 90 hari pasca kunjungan Sambang Pesantren. | [ ] | [ ] | [ ] | |
| 5.4 | Praktik baik perlindungan santri didokumentasikan dan ditularkan kepada santri dan asatidz angkatan berikutnya. | [ ] | [ ] | [ ] | |
| 5.5 | Pesantren menindaklanjuti masukan dari wali santri terkait keamanan fasilitas fisik asrama (penerangan, sanitasi, privasi). | [ ] | [ ] | [ ] | |
